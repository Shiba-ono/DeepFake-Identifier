# DeepFake Face Identifier

A binary image classifier built with PyTorch that distinguishes real human faces from AI-generated ones, targeting deepfake detection use cases.

## Overview

This project fine-tunes a pretrained EfficientNet-B0 model on a 140k image dataset of real and AI-generated faces. The goal was to explore machine learning fundamentals — transfer learning, data augmentation, model evaluation, and the real-world limitations of benchmark accuracy.

## Key Learnings

Achieved 100% test accuracy on in-distribution data
Diagnosed distribution shift as the root cause of failure on modern high-quality deepfakes — the model learned compression artifacts specific to the training dataset rather than generalisable fake-face features
Discovered that 100% validation accuracy is a red flag, not a success — it indicated the model memorised the dataset rather than learning transferable features
Understood the arms race between generative models and detectors as an unsolved research problem

## Limitations

Distribution shift: The model was trained on StyleGAN-generated faces from ~2020. Modern generators (Stable Diffusion, Midjourney, DALL-E 3) produce significantly higher quality images that the model has never seen and consistently misclassifies as real.
Dataset bias: Low file size (~30kb) and resolution of training fakes means the model likely learned compression artifacts rather than semantic fakeness.
Generalisation: This reflects a broader unsolved problem in deepfake detection — models trained on one generator rarely transfer well to another.
